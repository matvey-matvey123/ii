# 🤖 AI Assistant

Настоящий ИИ-ассистент на основе **OpenAI GPT** с веб-интерфейсом.

## ✨ Возможности

- 🧠 **Настоящий ИИ** — использует GPT-3.5/GPT-4
- 💬 **Красивый чат** с тёмной темой и анимациями
- 📝 **Поддержка кода** — форматирование блоков кода
- 🔄 **Память сессий** — ИИ помнит контекст диалога
- 📋 **Копирование диалога** одной кнопкой
- 🌐 **Адаптивный дизайн** — работает на всех устройствах
